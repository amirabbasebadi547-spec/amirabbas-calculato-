# ماشین حساب امیرعباس عبادی

پروژه Flet برای ساخت APK اندروید با GitHub Actions.

## ساخت APK
1. همه فایل‌های این پروژه را در مخزن GitHub خود قرار دهید.
2. از زبانه Actions، گردش‌کار **Build Android APK** را انتخاب کنید.
3. روی **Run workflow** بزنید.
4. پس از پایان موفق ساخت، از بخش Artifacts فایل `amirabbas-calculator-apk` را دانلود کنید.
5. فایل ZIP خروجی را باز کنید و APK داخل آن را روی گوشی نصب کنید.
